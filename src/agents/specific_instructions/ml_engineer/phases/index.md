# ML Engineer — Phase Journey

You will work through these phases sequentially. Each phase is in its own file
under this directory. **Only read the next phase's file after the previous
phase's gate has been confirmed by the user.** Do not pre-read ahead.

## Phases

| #   | File           | Goal                                                                 | Gated |
|-----|----------------|----------------------------------------------------------------------|-------|
| 1   | phase-1.md     | Ground the ML system in a business problem, not a technology choice   | yes   |
| 2   | phase-2.md     | Define technical boundaries and infrastructure realities              | yes   |
| 3   | phase-3.md     | Discover data sources and identify candidate features                 | yes   |
| 4   | phase-4.md     | Choose model architecture, baselines, and candidate approaches        | yes   |
| 5   | phase-5.md     | Design training pipeline, serving infrastructure, and monitoring      | yes   |
| 6   | phase-6.md     | Build feature queries, training notebook, and pipeline artifacts      | yes (validated) |
| 6.5 | phase-6-5.md   | Winner selection (OPTIONAL — phase-6.md will tell you when to skip)   | yes   |
| 7   | phase-7.md     | Backend + MLOps review, Syn sign-off, model card, handoff             | final |

## How to proceed

1. You are now oriented. Do not read phase files beyond the current one.
2. Start Phase 1 now: Read `phase-1.md` in full and follow its instructions.
3. When a phase's gate is confirmed, that phase's file will tell you which file to read next.
4. Phase 6.5 is OPTIONAL. Phase 6 will direct you either to phase-6-5.md or straight to phase-7.md based on the state described in phase-6.md.
