# Keybindings Reference

All keybindings registered by the Shards UI. On macOS use `Cmd`; on Linux/Windows use `Ctrl`.

## Global

| Keybinding | Action |
|---|---|
| `Cmd+P` | Quick Open (files) |
| `Cmd+T` | Symbol search (project-wide) |
| `Cmd+K` | Command Palette |
| `Cmd+,` | Open Settings |
| `Cmd+B` | Toggle sidebar |
| `Cmd+\` | Toggle split view |
| `Cmd+S` | Save current file |
| `Cmd+W` | Close current tab |
| `Cmd+Shift+T` | Reopen last-closed tab |
| `Cmd+F` | Find in current view (editor or chat) |
| `Cmd+Option+F` | Find & Replace in editor |
| `Shift+Tab` | Cycle permission mode |

## Sidebar focus

| Keybinding | Action |
|---|---|
| `Cmd+Shift+E` | Focus Explorer |
| `Cmd+Shift+G` | Focus Source Control |
| `Cmd+Shift+B` | Focus Bookmarks |

## Workspace

| Keybinding | Action |
|---|---|
| `Cmd+1` | Focus Chat pane |
| `Cmd+2` | Focus Editor pane |
| `Cmd+3` | Focus secondary split pane |

## Editor (Monaco)

| Keybinding | Action |
|---|---|
| `F12` | Go to Definition |
| `Shift+F12` | Find References |
| `Cmd+D` | Add next occurrence to selection |
| `Option+click` | Add cursor |
| `Cmd+/` | Toggle line comment |
| `Cmd+Shift+K` | Delete line |
| `Option+↑ / ↓` | Move line up/down |

## Chat

| Keybinding | Action |
|---|---|
| `Enter` | Send message |
| `Shift+Enter` | Newline in input |
| `Cmd+F` | Focus chat search bar |
| `↑ / ↓` (in search) | Navigate matches |

## Pinboard

| Keybinding | Action |
|---|---|
| `Cmd+Shift+P` | Pin current selection |
| `Cmd+D` | Bookmark current file/line |

## Quick Open modifiers

In the `Cmd+P` input:

| Prefix | Behavior |
|---|---|
| `@` | Symbol search within current file |
| `#` | Symbol search across project |
| `:42` | Jump to line 42 in current file |
